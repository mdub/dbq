# Architecture decision records

We record significant design decisions as Architecture Decision Records (ADRs),
following [Michael Nygard's format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

Each ADR documents a choice that affects the project's structure or approach, and covers:
  - the context
  - options considered
  - decision
  - consequences
